# Zuspaetkommen Protokoll (Vercel + Supabase)

Web-App fuer gemeinsames Eintragen von Zuspaetkommen.  
Eintraege werden zentral in Supabase (PostgreSQL) gespeichert und sind fuer alle sichtbar.

## Funktionen
- modernes, responsives UI
- neue Eintraege speichern
- letzte Eintraege anzeigen
- Eintraege loeschen
- persistente Speicherung in der Cloud

## Supabase Tabelle anlegen
SQL im Supabase SQL Editor ausfuehren:

```sql
create table if not exists public.late_entries (
  id bigint generated by default as identity primary key,
  teacher text not null,
  class_name text not null,
  date date not null,
  lesson integer not null,
  delay_minutes integer not null,
  status text not null,
  note text,
  created_by text not null,
  created_at timestamptz not null default now()
);
```

## Vercel ENV Variablen
In Vercel unter Project Settings -> Environment Variables:

- `SUPABASE_URL` = deine Supabase Project URL
- `SUPABASE_SERVICE_ROLE_KEY` = Service Role Key (nur serverseitig verwenden)

## Deploy
Projekt normal nach Vercel pushen/deployen.  
Die API liegt in `api/entries.js` und nutzt automatisch die ENV Variablen.

## Wichtige Dateien
- `api/entries.js` - serverseitige API fuer GET/POST/DELETE
- `index.html` - Oberflaeche
- `styles.css` - Design
- `script.js` - Frontend-Logik und API-Aufrufe
